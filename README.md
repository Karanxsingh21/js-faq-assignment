# JavaScript Interactive FAQ Assignment

## Overview
This project is an interactive FAQ webpage built using HTML, CSS, and JavaScript.  
It demonstrates Object-Oriented Programming (OOP) concepts and dynamic DOM manipulation.

## Features
- Clickable questions that toggle answers
- Smooth expand/collapse animation
- Modern UI with glassmorphism
- Accordion behavior (only one question open at a time)
- Animated gradient background

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## JavaScript Implementation
A `QAItem` class is used to represent each question-answer pair.

### QAItem Class Responsibilities
- Store question and answer text
- Render HTML dynamically
- Toggle answer visibility
